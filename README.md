# MOS Numerology

Статичний український дизайн-макет для погодження. HTML, CSS, мінімальний JavaScript для розкриття деталей за посиланням. Без пакетів, зовнішніх шрифтів, аналітики чи платіжної інтеграції.

- Відкрити `index.html` або виконати `python3 -m http.server 8080` у цій папці.
- Перевірка: `python3 verify.py` (Python 3 і Node для перевірки синтаксису JavaScript).
- `content.json`: 159 унікальних дослівних блоків із 205 текстових вузлів 5 сторінок Canva. Дублікати визначено лише після нормалізації пробілів. Оригінальні переноси збережено.
- `source-content.md`: читабельний архів тих самих текстів без bootstrap-токенів.
- `assets/`: 2 оригінальні фото та 1 оригінальна схема. Canva media IDs і URL наведено в `content.json`.
- Повні описи 4 послуг та підходу доступні в нативних акордеонах. Спільні повторювані умови оплати наведено один раз із посиланнями з інших послуг.
- Початкове формулювання строків `3–5-7 днів` збережено. Потрібне уточнення авторки перед остаточним погодженням.
- Твердження про здоров’я атрибутовано авторці. Видиме застереження: нумерологія не є науковою діагностикою або заміною медичної допомоги.

Джерело: https://mosnumerology.my.canva.site/ . Секретний продукт та авторські матеріали не мають вигаданих характеристик, деталей слід запитувати в авторки. Відгуки не додано. Макет не є затвердженим production-релізом.
